# Documentation checklist

- [ ] State what you personally built (no work system details)
- [ ] Include goal and tools
- [ ] Include network/system diagram
- [ ] Show implementation steps and important sanitized commands
- [ ] Add evidence of successful tests and failed tests
- [ ] Explain one or more troubleshooting decisions
- [ ] Remove secrets, PII, hostnames, domain names, private details before uploading
- [ ] Mark project status accurately
- [ ] Add concise resume bullet only after completion
